# 独立流程配置器

这是一个完全独立于 HIS 源代码目录、只监听本机 `127.0.0.1` 的可视化流程编辑器。Web 页面负责编辑和保存 JSON 工作流，本机 Python Agent 在当前 Windows 登录会话中使用 `pywinauto`、鼠标键盘、截图和 RapidOCR 操作已打开的 HIS 窗口。

## 启动

双击：

```text
启动流程配置器.cmd
```

启动后浏览器会自动打开：

```text
http://127.0.0.1:8765
```

启动脚本不依赖固定盘符、HIS 项目目录或外部虚拟环境。首次运行时会在流程配置器目录创建 `.venv` 并根据 `requirements.txt` 安装依赖；以后移动整个独立项目文件夹仍可直接启动。需要预先安装 Python 3.10 或更高版本，并在首次安装依赖时连接网络。联网安装默认使用清华 PyPI 镜像 `https://pypi.tuna.tsinghua.edu.cn/simple` 加速下载。

如果目标电脑不能联网，可以把预先下载的离线安装包放入 `rpa-flow-studio\wheelhouse`，启动程序会优先从该目录安装依赖。

如需使用管理员指定的现有 Python 环境，可以在启动前设置 `RPA_PYTHON` 为该环境的 `python.exe` 完整路径。

如需临时切换其他 Python 软件源，可在启动前设置 `RPA_PIP_INDEX_URL`；未设置时自动使用清华镜像。

运行任务前需要保持 HIS 窗口已经打开。执行过程中不要锁屏、切换 Windows 用户或操作鼠标键盘。

## 当前能力

- 点击左侧模块，将模块添加到流程；
- 拖动模块或使用上下箭头调整执行顺序；
- 修改步骤名称、启用状态和模块参数；
- 配置 HIS 文本输入、下拉项选择和勾选框状态；
- 按 `YYYY-MM-DD` 配置日期，并通过视觉布局分段填写年、月、日；
- 按自定义对象名称，通过视觉页面布局点击按钮、页签、菜单项等对象；
- 首次操作时截图并用 OCR 建立页面视觉元素地图，同一页面后续操作直接复用；
- 视觉地图按窗口类名、页面标识、尺寸和 DPI 分开缓存，并保留参考图、OCR 结果和业务目标坐标；
- 每个 OCR 步骤可独立配置定位方式、表格标题、目标列、截图范围和表格边界；
- 保存、重新加载 JSON 配置；
- 在“配置页”集中管理多个配置，支持新建、编辑和删除；
- 基于现有安全动作新增、修改和删除自定义操作模块；
- 运行完整流程，或运行到选中的步骤；
- 查看步骤级实时日志和最终输出路径；
- 运行日志区域可以收起或展开；
- 同一时间只允许一个桌面任务运行；
- 正在运行的任务可以请求取消；等待查询、等待页面和普通等待会立即响应取消，短暂的截图/OCR 动作会在当前动作完成后停止；
- 配置只能调用注册过的模块，不能执行任意 Python 代码。

## 通用视觉页面布局

对于没有可访问性/UIA 控件树的桌面系统，操作模块可以使用“视觉页面标识”
建立可复用页面模型。该能力不依赖具体 HIS 名称或固定坐标，模型按窗口标题、
窗口类名、页面标识、窗口尺寸、DPI 和页面结构状态隔离。

手动执行“识别并保存当前页面布局”时，会先等待页面加载稳定，然后强制进行完整
窗口 OCR 和整页预分类；每次都会保存为新的 Map，不会复用或覆盖旧 Map。普通
点击、填写、勾选等视觉操作没有配置该模块时，仍会自动匹配已有 Map；确实遇到
新页面且没有匹配 Map 时，也会自动建立完整页面 Map。

完整页面 Map 会保存：

- 页面参考图和完整 OCR 结果；
- 文字区域及上下左右邻接关系；
- 首次建立整页文字、表格、表头、输入框、下拉框和勾选框候选分类；
- 每个 OCR 文字及其可能角色，重复文字会单独记录为歧义目标而不会直接合并；
- 已分类控件直接复用；首次操作仍可按需校正并写回当前 Map；
- 悬浮菜单或下拉展开状态的独立页面模型。

每次视觉操作前会先快速截图并比较页面结构指纹。匹配已有状态时直接复用；
页面整体结构变化时创建新的 Map，不覆盖旧状态。日期选择器、下拉菜单和悬浮
菜单等局部变化会优先只 OCR 变化区域，减少等待时间。点击文字对象时，如果旧
Map 的同名坐标不在新出现的局部区域内，会自动建立子 Map，避免误点页面中原有
的同名标题。点击菜单子 Map 中的选项后，下一次视觉操作会排除菜单及其父页面，
优先匹配已有目标页；没有匹配状态时建立新的整页 Map。

页面结构指纹只保留控件边框、表格框架和列结构，并忽略输入值、表格数据行、
焦点、选中色和勾选状态。窗口尺寸或 DPI 不同会保存为同一逻辑页面的布局变体。
现场系统发生了明确页面跳转但自动判断不可靠时，可在流程中插入“识别并保存当前
页面布局”或兼容名称“重新识别整页”。这两个手动模块都强制建立新的完整 OCR
Map，原有历史 Map 继续保留。

日期字段通过“开始日期”“结束日期”等完整字段标签分别关联各自输入框，再在输入
框内容区内逐段点击年、月、日并填写；不会依赖重复的“年/月/日”文字，也不会对
整个日期控件发送全选命令。同行标签优先关联左右输入框，候选框与标签文字重叠
时会被拒绝；日期段坐标优先从输入框内的占位文字或已有日期文字推算。

页面模型保存在：

```text
configs\visual-maps\page-<页面指纹>\
  layout.json
  reference.png
```

该目录不会进入 Git。真实业务系统的参考图可能包含敏感信息，应使用无患者数据
的空白页面建图，或在使用后删除对应页面模型。“识别并保存当前页面布局”模块
支持强制创建一个新的识别版本；旧页面模型仍会保留。

“悬浮对象并识别展开布局”模块只移动鼠标并记录悬浮后的页面状态，不会自动
点击未知按钮。需要点击才能展开的菜单，应由用户明确配置安全的点击步骤。

## 标准 HIS 流程顺序

“配置页”中提供了一套示范程序，正确顺序为：

1. 连接 HIS 窗口；
2. 最大化 HIS 窗口；
3. 填写住院号并回车；
4. 等待患者查询结果；
5. 点击第一条查询结果；
6. 等待医嘱页面；
7. 截取当前位置；
8. 截取横向最右端；
9. OCR 标注审核字段。

“发送按键”“按窗口比例点击”“点击 UIA 控件”“等待”属于高级可选模块。上述专用 HIS 模块已经包含必要的输入、回车、点击和等待逻辑，标准流程中不需要重复添加这四个模块。

默认配置保存在：

```text
configs\default.json
```

截图和 OCR 标框图片默认保存到：

```text
output
```

自绘窗口识别后的坐标缓存保存在 `configs/visual-maps`。该目录不会进入
版本库；窗口移动不会导致缓存失效，窗口尺寸或 DPI 变化时会自动建立新地图。

## 主要文件

- `server.py`：本机 HTTP Agent 和配置接口；
- `workflow_engine.py`：JSON 校验、变量替换、顺序执行和任务状态；
- `rpa_modules.py`：可供页面编排的安全模块库；
- `visual_shape_detection.py`：视觉页面布局使用的通用输入框、下拉框和勾选框形状定位；
- `visual_state.py`：快速页面结构指纹、状态复用和弹出层变化区域检测；
- `his_automation.py`：项目自带的 HIS Windows 自动化适配器；
- `ocr_marker.py`：项目自带的 OCR 表格识别与标框模块；
- `web/`：可视化页面；
- `configs/default.json`：当前 HIS 医嘱取证流程。

## 变量

模块参数支持 `${变量名}`。默认流程使用：

```text
${hospitalization_number}
```

变量保存在配置文件中，也可以直接在对应操作模块的参数中填写具体值。

## 版本回溯

独立项目自带 `.gitignore`，`output`、日志、虚拟环境、Python 缓存和个人流程草稿不会进入版本库，避免运行截图或患者信息被纳入代码历史。

查看版本记录：

```text
cd /d D:\AI\AI_S\rpa-flow-studio-standalone
git log --oneline --decorate
```

需要回退时，先停止流程配置器并确认当前代码改动是否需要保留，再选择目标版本。为防止误覆盖未保存工作，建议把目标版本号交给维护人员执行回退。

## 后续扩展

新增能力时，在 `rpa_modules.py` 中实现处理函数并注册 `ModuleDefinition`。页面会通过 `/api/bootstrap` 自动取得新模块及其参数定义，不需要为每个模块重新编写前端页面。
